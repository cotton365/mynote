# 2.词嵌入和位置信息

词嵌入就是一个对应的可训练矩阵，每个token_id对应了一串512长度的向量，这样一个有n个token的句子变成了一个$n \times 512$的 X矩阵，这还没完，还有位置信息的输入

**因为矩阵乘法和自注意力机制本质上是“无序的”。不加位置编码时，交换 token 顺序只会使注意力矩阵的对应行、列一起交换；同一 token 对之间的分数不变。模型无法表示由顺序变化产生的新语义。”**
举例：位置交换仅仅是“行列变换”，但是最后计算注意力的值的时候，这里面“值没有变”（这个是关键），最后机器看到的结果或者概率分布，仅仅是两个向量交换的结果，但是语义本身已经发生了本质的变化，比如“他揍了我一顿”和“我揍了他一顿”，两者后面的语义截然不同，绝对不能是“仅仅两个向量的交换”
对于位置矩阵 $PE$ 中第 $pos$ 行（代表词在句子中的绝对位置）、第 $j$ 列（代表 512 维向量中的第几个特征通道）的元素，其计算公式根据列的**奇偶性**分为两种：

当特征通道索引 $j$ 为**偶数**（记作 $2i$）时： $$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{\frac{2i}{d_{\mathrm{model}}}}}\right)$$

当特征通道索引 $j$ 为**奇数**（记作 $2i+1$）时： $$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{\frac{2i}{d_{\mathrm{model}}}}}\right)$$
$d_{\mathrm{model}}$就是模型的特征维度，论文中固定为512
**低维通道（**$i$ **较小，高频）**：波长非常短（如 $2\pi \approx 6.28$ 个 token），在句子中变化极其剧烈。
**高维通道（**$i$ **较大，低频）**：波长极长（如几万个 token），在几百词的句子里，它的变化非常缓慢，几乎像是一条平缓的有斜率的直线。
>实际上，我们不是看绝对的pos的，而是相对的k，**也就是“我这个需要填入的token，他的上下文不同的token相对于他距离多少”**，而刚才说的公式，**描述的是“维度上的尺度”而不是“距离上的尺度”**
>因为i不论怎么变，这都是一个距离下不同维度的情况而已 如果模型训练后发现“这个token在相对近距离特别影响其他token，但是远距离不是”，**那么这里面的尺度上就会用上“频率高的那部分”，相反就是“频率低的那部分”**

# 3.ATTENTION
我们这里位置计算的矩阵和词嵌入计算的矩阵形状一致，我们这里先相加，然后一起扔进去计算，我们当$X_{\mathrm{final}}$是这里把“词嵌入”的和“位置计算”的两个结果相加了的矩阵，$n \times 512$

**补充：为什么要这么做？$\operatorname{Attention}(A+B) \overset{?}{=} \operatorname{Attention}(A)+\operatorname{Attention}(B)$**
>令：
  $Q_A=AW^Q,\quad Q_B=BW^Q$
  $K_A=AW^K,\quad K_B=BW^K$
  先相加再计算：
  $QK^T=(Q_A+Q_B)(K_A+K_B)^T$
  展开：
  $Q_AK_A^T +Q_AK_B^T +Q_BK_A^T +Q_BK_B^T$
  中间两项很关键：
  **$Q_AK_B^T$：token 内容与对方位置之间的关系
  $Q_BK_A^T$：当前位置与对方 token 内容之间的关系。**
  若分别计算再相加，只保留“内容对内容”和“位置对位置”，缺少两个交叉关系。之后还有 softmax，差异进一步扩大。因此训练效果不等价。





对于一个单头注意力机制（这里维度设为 $d_k = d_v = 64$），其背后的数学运行步骤非常直观：


### 步骤 1：空间线性投影

通过三个可学习的矩阵将 $n \times 512$ 的输入投影到低维子空间：

1. $Q$ **矩阵**：$Q = X W^Q \in \mathbb{R}^{n \times 64}$
2. $K$ **矩阵**：$K = X W^K \in \mathbb{R}^{n \times 64}$
3. $V$ **矩阵**：$V = X W^V \in \mathbb{R}^{n \times 64}$ _(其中_ $W^Q, W^K, W^V \in \mathbb{R}^{512 \times 64}$ _都是待训练的参数)_

### 步骤 2：计算相关度矩阵

计算 $Q$ 和 $K$ 的内积： $$S = Q K^T \in \mathbb{R}^{n \times n}$$
**第 $i$ 行、第 $j$ 列的元素 $S_{i,j} = \mathbf{q}_i \cdot \mathbf{k}_j$。这就是向量 $\mathbf{q}_i$ 与向量 $\mathbf{k}_j$ 的点积**

### 步骤 3：缩放与 Softmax 归一化

$$P = \operatorname{softmax}\left(\frac{S}{\sqrt{64}}\right) \in \mathbb{R}^{n \times n}$$
为了分析 $S$ 的大小，论文作者在脚注中做了一个标准的统计学假设： 假设 $\mathbf{q}$ 和 $\mathbf{k}$ 向量里的每一个元素，都是**独立，同分布**的随机变量，且它们的：
**均值（Mean）** 为 $0$：$\mathbb{E}[q_i] = \mathbb{E}[k_i] = 0$
**方差（Variance）** 为 $1$：$\operatorname{Var}(q_i) = \operatorname{Var}(k_i) = 1$
$$S = \mathbf{q} \cdot \mathbf{k} = \sum_{i=1}^{d_k} q_i k_i$$
在S里面的任何一个元素，$\operatorname{Var}(q_i k_i) = \mathbb{E}[q_i^2 k_i^2] - (\mathbb{E}[q_i k_i])^2$，结果是1，
**再看整个累加和** $S$ **的方差**： 因为这 $d_k$（64）个相乘项之间也是相互独立的，**独立随机变量之和的方差，等于各自方差之和**： $$\operatorname{Var}(S) = \sum_{i=1}^{d_k} \operatorname{Var}(q_i k_i) = \sum_{i=1}^{d_k} 1 = d_k$$
这里S的标准差代表数据实际波动的平均物理尺度，我们这里S去除$\sqrt{d_k}$,这样标准差变成了1，后续归一化就不会有影响

### 步骤 4：特征加权重构
**一个 $n \times n$ 的归一化概率矩阵 $P$，乘以 $n \times 64$ 的特征矩阵 $V$，得到最终的输出 $Y \in \mathbb{R}^{n \times 64}$**
$$Y = P V \in \mathbb{R}^{n \times 64}$$
我们把这个公式拆开，看输出矩阵 $Y$ 的第 $i$ 行（即第 $i$ 个 Token 融合特征后的向量）： $$\mathbf{y}_i = P_{(i,1)}\mathbf{v}_1 + P_{(i,2)}\mathbf{v}_2 + \dots + P_{(i,n)}\mathbf{v}_n$$
**几何上的直观展现**： 在 64 维的内容空间里，原本分布着 $n$ 个点（每个 Token 对应的 $\mathbf{v}_j$ 向量）。 自注意力计算的最终结果，是把第 $i$ 个 Token 的新向量 $\mathbf{y}_i$，拉向那些与它相似度高（即 $P_{i,j}$ 大）的 Token 的向量 $\mathbf{v}_j$。
>如果 Token 1 极其关注 Token 3，那么它的输出 $\mathbf{y}_1$ 就会在 64 维空间中，被强烈拉向 $\mathbf{v}_3$ 的位置。


### 这个过程说明了什么
 - 数学上，点积本质上表述的就是**向量夾角与模长**，这里的点积计算本身就是说“关系怎么样”，**Token A（“我”）** 和 **Token B（“他”）** 之间，在数学计算里面，$\text{Score} = \mathbf{q}_A \cdot \mathbf{k}_B$ ，q在这里就显现为“我和他有多般配”，而k就是“他和我有多般配”
 - 我们不能光使用原本的X去计算点积，我们计算的是 $Q K^T = X (W^Q W^{K^T}) X^T$。由于 $W^Q W^{K^T}$ 一般不是对称矩阵，这让模型能够拥有**非对称的关联表达能力**：A 可以极其关注 B，但 B 可以完全不关注 A。
- **因为词汇本身是非对称的（在动宾结构“吃苹果”中，动词“吃”强烈需要寻找一个名词，但名词“苹果”并不一定强烈依附于动词“吃”）**
- V区分的原因是Q K是“**用来测量两个词是否相关的特征**”（比如它们是不是动词、名词、单复数，这些归 $Q, K$ 测量，但是“**它们本身携带的、需要传递给下一层网络的实际信息**”（比如它的实际语义，这归 $V$ 表达）**应该是相互解耦、不应该混淆的**。这里就用了额外的一个V去表述语义
