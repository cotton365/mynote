1. **尺寸与容量 (size vs capacity)**：
    - `size()` 返回当前字符串中的字符数。
    - `capacity()` 返回在不重新分配内存的情况下字符串能容纳的最大字符数。
    - **工程应用**：当你的 `Config` 读入超长路径时，字符串会自动扩容；你可以用 `reserve()` 预留空间以减少分配开销。




# 核心操作：看懂 `config.cpp` 里的逻辑

通过你的源代码，我们可以学习 `std::string` 最实用的几个成员函数：

1. **搜索操作 (****find** **系列)**：
    - `find_first_not_of(" \t\r")`：在 `trim` 函数中被用来定位第一个非空白字符的位置。
    - `find_last_of('/')`：在 `configDir` 函数中被用来定位最后一个斜杠，从而分割目录和文件名。
    - **特殊值** **npos**：这是一个静态常量，用于表示搜索未匹配。在你的代码中，如果搜索结果等于 `std::string::npos`，则说明没找到目标字符。
2. **子串提取 (****substr****)**：
    - `s.substr(pos, len)`：创建一个包含从 `pos` 开始、长度为 `len` 的子串的新字符串。
    - 在你的代码中，解析配置目录时，`path.substr(0, pos)` 提取了斜杠前的所有内容。
3. **C 风格接口 (****c_str****)**：
    - 当你需要调用底层的 C 函数（如你的代码中调用的 `std::strtoll`）时，需要使用 `s.c_str()` 获得一个以空字符结尾的 `const char*` 指针。

# 现代 C++ 增强：`string_view` (C++17)

在你的工程中，虽然主要使用了 `std::string`，但了解它的轻量级兄弟 **std::string_view** 对深入理解很有帮助：

- **不拥有所有权**：它只是一个“指针 + 长度”的组合，用于以只读方式观察已存在的字符串。
- **零拷贝**：在处理像 `parseNumber` 这种只需要读取字符串而不需要修改它的函数时，使用 `string_view` 作为参数可以完全避免临时字符串的构造，极致提升性能。
