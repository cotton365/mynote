**1. import torch.nn as nn**  
**✅** **是干什么的？**  
这是 PyTorch 的**神经网络模块库**。  
你定义网络结构时用的所有层（Linear, Conv2d, ReLU 等）都来自这里。  
**📌** **你什么时候要用？**  
**只要你写神经网络，就一定要用！**  
不管是 LunarLander、CartPole、Atari、还是你自己设计的网络，只要用 PyTorch，就离不开 nn。  
**🔁** **换环境要改吗？**  
❌ **完全不用改！**  
nn.Linear(8, 128) 在 LunarLander 里用，在 CartPole 里也用（只是输入维度可能变）。  
**💡** **难吗？**  
🟢 **非常简单**！  
你就记住：**所有网络层都从** **nn** **里拿**，比如：  
self.fc = nn.Linear(in_features, out_features)￼self.relu = nn.ReLU()￼
 
**2. import torch.nn.functional as F**  
**✅** **是干什么的？**  
这是 PyTorch 的**函数式接口**，提供激活函数（如 F.relu）、损失函数（如 F.mse_loss）、概率操作（如 F.softmax）等。  
和 nn 的区别：

- nn.ReLU() 是一个**可保存状态的模块**（适合放在 __init__ 里）
- F.relu(x) 是一个**纯函数**（适合在 forward 里临时调用）

**📌** **你什么时候要用？**  
当你需要：

- 把 logits 转成概率 → F.softmax(logits, dim=-1)
- 计算 MSE 损失 → F.mse_loss(pred, target)
- 用 tanh/relu 激活 → F.tanh(x)

**🔁** **换环境要改吗？**  
❌ **基本不用改！**  
F.softmax 在 LunarLander 里用，在 Atari 里也用（输出动作概率）。  
⚠️ 唯一可能变的是：**连续动作环境**（如 Pendulum）不用 softmax，而用 tanh 或高斯分布 —— 但那是算法层面的改变，不是 F 本身的问题。  
**💡** **难吗？**  
🟢 **很简单！**  
你就把它当成“工具箱”，需要什么函数就拿什么。
 
**3. from torch.distributions import Categorical**  
**✅** **是干什么的？**  
这是 PyTorch 提供的**概率分布工具**。  
Categorical 表示**离散动作的分类分布**（比如有 4 个动作，每个动作有一个概率）。  
它让你能：

- 从概率中**采样动作**：dist.sample()
- 计算**某个动作的** **log** **概率**：dist.log_prob(action)

这两个操作是**策略梯度算法（如** **A2C****、****PPO****）的核心**！  
**📌** **你什么时候要用？**  
✅ **只有当你处理离散动作空间（****Discrete Action Space****）时才需要！**  
LunarLander-v3 的动作空间是：  
env.action_space￼# Discrete(4) ← 4个离散动作￼  
所以你需要 Categorical。  
**🔁** **换环境要改吗？**  
✅ **要看新环境的动作类型！**

|   |   |   |
|---|---|---|
|**环境类型**|**动作空间**|**需要什么分布？**|
|**LunarLander, CartPole, MountainCar**|Discrete(n)|✅ Categorical|
|**Pendulum, BipedalWalker, CarRacing**|Box(low, high)（连续）|❌ 用 Normal（高斯分布）|
|**Atari** **游戏**|Discrete(n)|✅ Categorical|

👉 所以：**如果你只玩离散动作的环境（大多数入门环境都是），就一直用** **Categorical****，不用改！**  
**💡** **难吗？**  
🟡 **稍微有点概念，但用起来很简单！**  
你只需要记住两行：  
probs = actor(state) # 输出 [0.1, 0.7, 0.1, 0.1]￼dist = Categorical(probs) # 包装成概率分布￼action = dist.sample() # 采样一个动作（比如 1）￼log_prob = dist.log_prob(action) # 计算 log(0.7)￼  
这就是策略梯度需要的全部！
