1. 引用与原变量共享内存地址  
在代码中，&a 和 &b 的地址是相同的，说明 b 并不是一个独立的变量，而是 a 的别名。对 b 的任何操作实际上都是对 a 的操作。  
2. 引用的绑定是不可更改的  
一旦 b 被初始化为 a 的引用，它就始终引用 a，无法再引用其他变量。  
3. 引用的值修改会影响原变量  
当你通过 b 修改值（如 b = 20），实际上是修改了 a 的值。这是因为 b 和 a 指向的是同一块内存。  
4. 引用的用途  
• 提高代码可读性：通过引用可以避免直接操作指针，代码更简洁。  
• 减少复制开销：在函数参数传递中，使用引用可以避免拷贝大对象，提高性能。  
总结：引用是变量的别名，操作引用等同于操作原变量，它们共享同一块内存地址。这种性质在需要高效传递数据或修改原变量时非常有用。
